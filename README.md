# Warehouse Map

An interactive warehouse mapping tool to help locate and identify items by ID.

## Features

- 🔍 Search for items by ID (e.g., RW-PR01)
- 📍 Visual highlighting of located items
- 🎨 Interactive SVG-based warehouse layout
- ⚡ Fast, client-side search

## How to Use

1. Enter an item ID in the search box
2. Click "Find" or press Enter
3. The item will be highlighted in green on the map
4. Click "Clear" to reset the search

## Files

- `index.html` - Main webpage with search functionality
- `warehouse.svg` - SVG map of the warehouse layout

## Deployment

This project is deployed to `map.jkbeachum.com` via GitHub Pages.

## Local Development

Simply open `index.html` in a web browser to test locally.
